# Inventory and Items

## Item classes

- Weapons
- Ammunition
- Mission items
- Clothing
- Consumables if used
- Collectibles
- Vehicle keys/ownership tokens

## Data fields

```text
item_id
display_name
category
stackable
max_stack
weight(optional)
value
icon
mesh
usage_action
```

Keep the inventory simple unless inventory management itself becomes a core mechanic.
