# Dialogue and Localization

## Language approach

A Bengaluru-inspired setting can naturally use a mix of Kannada and English, with additional languages appearing contextually and respectfully.

## Requirements

- Subtitle-first pipeline
- Dialogue IDs, never raw text embedded across Blueprints
- Translation-ready string tables
- Speaker metadata
- Emotion/delivery tags
- Audio filename convention

## Avoid

- Excessive caricature accents
- Treating one language as “default intelligence” and another as comic relief
- Hardcoding text into textures when it should be localizable
