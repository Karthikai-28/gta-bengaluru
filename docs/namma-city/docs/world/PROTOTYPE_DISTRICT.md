# Prototype District Specification

## Size

Approx. 2 × 2 km compressed central-Bengaluru-inspired district.

## Required zones

- Main boulevard
- Retail/nightlife street
- Dense market street
- Park
- Government/monument-inspired landmark zone
- Parking structure
- Small alley network
- Flyover/underpass segment
- Metro-inspired corridor if licensing/art direction permits

## Required gameplay locations

- Player garage
- Safehouse
- Police station exterior
- Clinic/hospital exterior
- Weapon/equipment fictional shop if used by design
- Clothing store
- Cafe
- Parking garage
- Mission warehouse/interior
- Corporate office lobby/interior

## Signature route

Design one chase route that transitions:

car → traffic jam → motorcycle → flyover → crash → foot chase → park/market escape.

This becomes the showcase sequence for the vertical slice.
