# Interiors

Do not attempt to make every building enterable.

## Vertical-slice target

Build 5–10 high-quality interiors:

- Player garage/workshop
- Safehouse/apartment
- Cafe
- Small retail shop
- Parking structure
- Corporate lobby/office floor
- Warehouse
- Mission-specific room

## Interior tiers

### Tier A — Story interior
Fully authored, interactive, mission-ready.

### Tier B — Reusable shop
Modular layout generated from a small kit.

### Tier C — Fake interior
Window/parallax/closed-door presentation only.

## Streaming

Interior loading must not require keeping the surrounding district at maximum detail when it is not visible.
