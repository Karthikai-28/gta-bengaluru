## Asset rules

- Consistent scale: centimeters in Unreal
- Real-world plausible dimensions
- Pivot conventions documented
- Collision generated intentionally
- LOD strategy required
- Texture budgets by asset class
- Shared material instances
- Decals for dirt, posters, road wear, and signs
