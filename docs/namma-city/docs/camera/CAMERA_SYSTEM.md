# Camera System

## Modes

- Third-person exploration
- Aim camera
- Sprint camera
- Vehicle chase camera
- Motorcycle camera
- Interior/hood camera later
- Cinematic mission camera
- Photo mode later

## Requirements

- Camera collision avoidance
- Smooth shoulder swap
- Adjustable FOV
- Speed-sensitive vehicle FOV
- Camera shake layers with user-controlled intensity
- Aim-assist hooks for controller without forcing aim assist on mouse
- No mission logic should directly manipulate the camera without using the camera manager/interface
