## HUD principles

Keep the screen clean. Prefer contextual prompts and phone-based interfaces over permanent UI clutter.

## HUD elements

- Health
- Armor if used
- Ammo
- Heat level
- Minimap
- Mission objective
- Context prompt

## Accessibility

- Subtitle size
- Subtitle background
- Color-safe objective indicators
- Hold/toggle options for aim/sprint
- Full key rebinding
- Controller remapping where possible
- Camera shake slider
- Motion blur toggle
- FOV slider
