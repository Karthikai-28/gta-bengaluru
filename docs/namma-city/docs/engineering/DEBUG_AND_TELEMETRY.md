# Debug Tools and Telemetry

## Developer overlays

- FPS/frame time
- CPU/GPU frame breakdown shortcut
- NPC count by simulation LOD
- Vehicle count
- Active police units
- Heat state
- Current district
- World Partition cells
- Mission state/objective
- Traffic lane visualization
- Nav paths

## Gameplay telemetry for local playtests

Track locally:

- Mission start/completion/failure
- Failure reason
- Time per objective
- Death location
- Vehicle used
- Heat level reached
- Frame-time spikes

Keep telemetry privacy-conscious and opt-in before any external collection.
