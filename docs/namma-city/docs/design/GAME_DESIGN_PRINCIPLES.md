# Game Design Principles

1. **Bengaluru is the identity, not a skin.** Traffic, weather, mobility, language, neighborhoods, technology, markets, and social rhythms affect gameplay.
2. **Fun beats geographic accuracy.** Compress distances and remove repetition.
3. **Systems interact.** Rain affects roads; traffic affects pursuit; witnesses affect police; time affects crowds.
4. **Local without caricature.** Build recognizable urban character respectfully.
5. **Data-driven content.** New vehicles, weapons, NPCs, shops, and missions should require minimal new code.
6. **Prototype before scale.** Never add another district to avoid fixing an unfun core loop.
7. **Performance is a feature.** Every population/world system needs LOD and budgets.
8. **Originality by default.** Use GTA only as a genre reference, not as an asset/design source to duplicate.
