# VFX

## Core effects

- Tire smoke
- Dust
- Road spray
- Rain impact
- Puddles
- Sparks
- Broken glass
- Vehicle damage smoke
- Muzzle flash
- Impact effects
- Explosion effects
- Blood/gore level according to final rating target
- Ambient dust/pollen
- Construction dust

## Technical rules

Use Niagara. Create scalability tiers. Expensive effects must expose spawn-count and distance controls. Avoid persistent GPU-heavy effects hidden behind geometry.
